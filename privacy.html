Privacy, quietly.

tabzen is built for calm tab management, with data minimized and user control first.

Overview

This policy explains what tabzen processes, where data is stored, and how privacy is protected. tabzen is a browser-side productivity extension with local Smart Group and local analysis. Core use does not require an account.

Local-First Processing

  • tabzen uses local Smart Group and local analysis to organize tabs.
  • Core grouping, scoring, and cleanup decisions are computed inside your browser environment.
  • tabzen does not require external analysis endpoints for normal operation.

Data We Store Locally

  • Saved tabs and archive items (title, URL, favicon, timestamps).
  • Tab history signals used for prioritization and stale-tab cleanup.
  • User preferences such as grouping keywords, priority sites, cleanup defaults, and appearance settings.
  • Zen Mode session state needed to restore tabs you intentionally parked.

Where Data Lives

  • Extension data is stored in your browser's extension storage and local IndexedDB area.
  • tabzen does not run a personal cloud account for syncing your tab history.
  • Your data remains tied to your local browser profile unless you export or sync via browser-level tools you control.

Permissions and Why They Are Used

  • tabs: read tab metadata and perform tab actions you trigger (focus, close, move, pin).
  • storage: persist your local settings and saved state.
  • sidePanel: display tabzen in Chrome side panel.
  • sessions: recover recently closed sessions for user-invoked undo.

Network Access

  • tabzen does not need broad host access to read website content.
  • tab data organization is designed to run locally without sending page bodies for analysis.
  • When opening websites in your browser, network traffic is handled by Chrome as part of normal browsing, not by tabzen as a data broker.

What We Do Not Do

  • No account sign-up required for core usage.
  • No sale of personal data.
  • No ad targeting based on your browsing activity.
  • No hidden background data collection beyond the features you use.

Data Retention

  • Saved tabs and history remain until you remove them or uninstall the extension.
  • Zen temporary queue items are intended to be restored and cleared as part of the Zen workflow.
  • You can reset or clear local records at any time from the extension interface.

Security Posture

  • tabzen follows minimum-permission design and only requests capabilities needed for tab management features.
  • No credential vault is required for core local features.
  • We aim to reduce data movement and keep processing close to the browser runtime.

User Control

  • You can clear saved tabs and local records from the extension UI.
  • You can uninstall the extension to remove its runtime access.

Children's Privacy

tabzen is not intended to collect personal information from children. If you believe sensitive personal data was stored unintentionally in tab titles or URLs, remove those records locally and uninstall the extension if needed.
